# Studium

서강대학교 열람실의 빈 좌석 수·좌석 번호·빈자리 예상 정보를 확인하는 Windows 앱입니다.

**[Studium.exe 다운로드](https://github.com/miso7236/Studium-releases/releases/latest/download/Studium.exe)** · [전체 배포 파일과 변경 사항](https://github.com/miso7236/Studium-releases/releases/latest)

Windows 10/11 64비트용입니다. GitHub 로그인, Git, Python 설치 없이 실행할 수 있습니다. 이 저장소는 실행 파일 배포와 업데이트에 사용합니다.

## 시작하기

1. `Studium.exe`를 쓰기 가능한 폴더에 저장하고 실행합니다.
2. **설정 → 열람실 선택**에서 원하는 열람실을 선택합니다.
3. **자동 확인 시작**을 누릅니다. PC가 켜져 있고 인터넷에 연결되어 있어야 합니다.
4. 디스코드 알림을 원하면 **설정 → 디스코드 연결**에 본인 채널의 웹훅 주소를 저장합니다. 웹훅은 선택 사항이며 다른 사람의 설정 파일을 복사할 필요가 없습니다.

## 자동 업데이트

자동 설치는 기본 켜짐입니다. 실행 10초 후와 이후 6시간마다 이 공개 저장소의 최신 정식 릴리스를 인증 없이 확인합니다. **설정 → 업데이트 → 지금 확인 및 업데이트**로 바로 확인할 수도 있습니다.

새 실행 파일의 크기·SHA-256을 검증한 뒤 앱을 다시 시작합니다. 설정과 자동 확인 상태를 유지합니다. 인터넷 연결이나 GitHub 요청 제한으로 확인에 실패하면 기존 앱을 계속 사용합니다. 자동 업데이트를 끄면 수동으로 업데이트할 수 있습니다.

v1.6.2 이하 앱은 비공개 배포 경로를 사용했습니다. 기존 저장소 접근 권한이 없는 사용자는 기존 앱을 **설정 → 프로그램 종료**로 종료하고 이곳의 최신 실행 파일로 한 번 교체하세요. 이후에는 GitHub 인증이 필요 없습니다. 시작 프로그램을 등록했다면 기존 EXE 경로와 파일명을 유지하세요.

개인 설정은 `%LOCALAPPDATA%\InventumSeatMonitor`에 저장됩니다. 기존 설정 호환을 위해 폴더 이름을 유지합니다. 배포 파일에는 개발자의 웹훅·GitHub 토큰·개인 설정이 포함되지 않습니다.

## 배포 파일

- `Studium.exe`: 단일 실행 파일.
- `Studium-vX.Y.Z-Windows-x64.zip`: 실행 파일, 사용 안내, 외부 라이브러리 라이선스와 pystray 소스.
- `InventumSeatMonitor.exe`: 이전 파일명을 사용하는 자동 업데이트용 호환 실행 파일. Studium.exe와 내용이 같습니다.
- `SHA256SUMS.txt`: 배포 파일의 SHA-256 값.

이 앱은 서강대학교의 공식 앱이 아닙니다. 학교에서 제공하는 공개 현황을 표시하며 좌석 예약은 하지 않습니다. 빈자리 예상은 학교 페이지의 표시값으로, 실제 해지나 예약 가능 시각을 보장하지 않습니다.
